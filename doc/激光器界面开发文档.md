# 激光器界面开发文档

本文档面向上位机/界面开发，说明激光器相关状态显示、报警复位、功率控制和打印层参数设置使用的 TLV。

## 基本约定

- 多字节字段均为小端序。
- 帧路由需要同时匹配 `Port + Cmd + Tlv-Type`。
- `CMD_SNESOR_VALUE_REPORT` 的宏名按当前固件源码拼写保留。
- 激光器报警复位只针对 `APP_ALARM_CODE_LASER_ALARM = 1301`，即 payload 小端字节为 `15 05`。

## 1. 激光器状态上报

`TLV_SENSOR_REPORT_3ST` 由 MCU 周期主动上报，用于界面显示激光器型号、状态、报警、功率、温度和电流。

> 旧的 `TLV_SENSOR_REPORT_2ST`（`0x03`，8 字节，不含型号与电流）已弃用：下位机停发，上位机不再解析。当前仅保留 3ST。

| 项目 | 值 |
| ---- | -- |
| 方向 | MCU -> SOC/HMI |
| Port | `PORT_SENSORS_TASK` (`0xA5`) |
| Cmd | `CMD_SNESOR_VALUE_REPORT` (`0x9B`) |
| Tlv-Type | `TLV_SENSOR_REPORT_3ST` (`0x04`) |
| Tlv-Len | `11` |

payload（多字节均为小端）：

| Value 字节 | 字段 | 类型 | 说明 |
| ---------- | ---- | ---- | ---- |
| `value[0]` | `laser_type` | `uint8_t` | 激光器型号，见 1.1 |
| `value[1..2]` | `laser_status` | `uint16_t LE` | 状态 bitfield，bit 含义随型号变化，见 1.2 |
| `value[3..4]` | `laser_alarm` | `uint16_t LE` | 报警打包值，bit 含义随型号变化，见 1.3 |
| `value[5..6]` | `laser_power` | `uint16_t LE` | 功率原始值，单位随型号变化，见 1.4 |
| `value[7..8]` | `laser_temperature` | `uint16_t LE` | 温度原始值，语义随型号变化，见 1.5 |
| `value[9..10]` | `laser_current` | `uint16_t LE` | 电流原始值，单位随型号变化，见 1.6 |

解析 `laser_status` / `laser_alarm` 及各单位前，必须先读取 `laser_type` 选择对应表。

### 1.1 `laser_type`

| 值 | 宏 | 说明 |
| -- | -- | ---- |
| `1` | `JFSC_LASER` | 风冷 JFSC 激光器 |
| `2` | `AL_LASER` | 200W 风冷 AL 激光器 |

### 1.2 `laser_status`（按型号）

同一字段在不同激光器上 bit 定义不同，界面必须按 `laser_type` 选表解析。

#### JFSC（`laser_type = 1`）

`laser_status` 来自 JFSC 寄存器 `0x0066`。

| bit | 含义 | 界面建议 |
| --- | ---- | -------- |
| bit0 | 红光输出中 | 可显示为“红光开启” |
| bit1 | 激光输出中 | 可显示为“激光输出中” |
| bit2 | 激光器 Ready | 可显示为“Ready” |
| bit3 | 外部输出信号有效 | 可显示为“外部输出有效” |
| bit4..15 | 当前固件未定义 | 建议保留为原始值 |

#### AL（`laser_type = 2`）

`laser_status` 由 MCU 打包：离散输入红光/激光使能状态 + 保持寄存器控制方式。

| bit | 含义 | 界面建议 |
| --- | ---- | -------- |
| bit0 | 红光使能状态 | 可显示为“红光开启” |
| bit1 | 激光使能状态 | 可显示为“激光开启” |
| bit2 | 控制方式：`0`=外控，`1`=内控 | 可显示为“外控/内控” |
| bit3..15 | 当前固件未定义 | 建议保留为原始值 |

注意：JFSC 的 bit2 是 Ready，AL 的 bit2 是内外控，**同 bit 不同含义**。

### 1.3 `laser_alarm`（按型号）

当 `laser_alarm != 0` 时，固件会把它归并为激光器总报警 `APP_ALARM_CODE_LASER_ALARM = 1301`。界面可用 bit 详情展示具体原因，用报警号 `1301` 做复位操作。

#### JFSC（`laser_type = 1`）

`laser_alarm` 是两个 JFSC 报警寄存器打包后的 16 位值：

```text
laser_alarm[7:0]  = JFSC register 0x0067 的低字节
laser_alarm[15:8] = JFSC register 0x0081 的低字节
```

低字节 `laser_alarm[7:0]`（寄存器 `0x0067`）：

| `laser_alarm` bit | 含义 | 界面建议 |
| ----------------- | ---- | -------- |
| bit0 | PD1 报警 | 显示“PD1 报警” |
| bit1 | PD2 报警 | 显示“PD2 报警” |
| bit2 | Interlock 联锁报警 | 显示“联锁报警” |
| bit3 | DB25 急停报警 | 显示“DB25 急停报警” |
| bit4 | QCW 脉宽报警 | 显示“QCW 脉宽报警” |
| bit5 | QCW 占空比报警 | 显示“QCW 占空比报警” |
| bit6..7 | 当前固件未定义 | 建议保留为原始值 |

高字节 `laser_alarm[15:8]`（寄存器 `0x0081`）：

| `laser_alarm` bit | 含义 | 界面建议 |
| ----------------- | ---- | -------- |
| bit8 | MCU 温度报警 | 显示“MCU 温度报警” |
| bit9 | 泵浦过流报警 1 | 显示“泵浦过流 1” |
| bit10 | 泵浦过流报警 2 | 显示“泵浦过流 2” |
| bit11 | QBH 安装报警 | 显示“QBH 安装报警” |
| bit12 | 泵浦电压报警 | 显示“泵浦电压报警” |
| bit13 | QBH 温度报警 | 显示“QBH 温度报警” |
| bit14 | 电压报警 | 显示“电压报警” |
| bit15 | 当前固件未定义 | 建议保留为原始值 |

#### AL（`laser_type = 2`）

`laser_alarm` 由输入寄存器 `000CH`..`0015H` 打包：原始值 `0`（正常）或 `1`（屏蔽）记为无报警（bit=0），其它值记为有报警（bit=1）。

| `laser_alarm` bit | 含义 | 界面建议 |
| ----------------- | ---- | -------- |
| bit0 | ALD_CH1 电流告警 | 显示“ALD 电流告警” |
| bit1 | ALD_CH1 电压告警 | 显示“ALD 电压告警” |
| bit2 | ALD_CH1 温度告警 | 显示“ALD 温度告警” |
| bit3 | 光纤盘温度告警 | 显示“光纤盘温度告警” |
| bit4 | PCB 温度告警 | 显示“PCB 温度告警” |
| bit5 | 凝露告警 | 显示“凝露告警” |
| bit6 | 包层光 PD 告警 | 显示“包层光 PD 告警” |
| bit7 | 光纤熔断 | 显示“光纤熔断” |
| bit8 | 急停 | 显示“急停” |
| bit9 | 服务期 | 显示“服务期告警” |
| bit10..15 | 当前固件未定义 | 建议保留为原始值 |

注意：JFSC 与 AL 的 bit0 起含义完全不同，必须按型号解析。

### 1.4 `laser_power`

| 型号 | 来源 / 单位 | 界面换算 |
| ---- | ----------- | -------- |
| JFSC | 寄存器 `0x0069`，原始值通常 `0..255` | `power_percent = laser_power * 100 / 255` |
| AL | 保持寄存器 `000EH`，单位 `0.1%` | `power_percent = laser_power / 10` |

### 1.5 `laser_temperature`

| 型号 | 含义 | 单位 |
| ---- | ---- | ---- |
| JFSC | 泵源温度（寄存器 `0x01F4`） | 原始 `uint16_t`，界面按摄氏度整数显示 |
| AL | ALD_CH1 温度（输入寄存器 `0005H`） | `0.1℃`，显示温度 = `laser_temperature / 10` |

### 1.6 `laser_current`

| 型号 | 含义 | 单位 |
| ---- | ---- | ---- |
| JFSC | 泵源电流（寄存器 `0x01F6`） | `current_A = laser_current / 100` |
| AL | ALD_CH1 电流（输入寄存器 `0003H`） | `0.1A`，`current_A = laser_current / 10` |

## 2. 激光器报警复位

界面复位激光器报警时，向 `AlarmSafetyTask` 发送 `TLV_ALARM_EVT_RESET`。该复位命令必须携带激光器报警号 `1301`，不要用于其它报警号。

| 项目 | 值 |
| ---- | -- |
| 方向 | SOC/HMI -> MCU |
| Port | `PORT_ALARM_TASK` (`0xA3`) |
| Cmd | `CMD_ALARM_EVT_RESPONSE` (`0x82`) |
| Tlv-Type | `TLV_ALARM_EVT_RESET` (`0x01`) |
| Tlv-Len | `2` |

payload:

| Value 字节 | 字段 | 类型 | 说明 |
| ---------- | ---- | ---- | ---- |
| `value[0..1]` | `alarm_code` | `uint16_t LE` | 固定为 `1301`，字节为 `15 05` |

处理链路：

1. 上位机发送 `TLV_ALARM_EVT_RESET`，`alarm_code = 1301`。
2. `AlarmSafetyTask` 校验报警状态和复位策略。
3. 如果需要激光器任务执行复位，固件会转发给 `LaserTask`。
4. `LaserTask` 执行激光器清报警动作。

## 3. 报警复位结果

`TLV_ALARM_EVT_RESET_RESULT` 是业务 task 向 `AlarmSafetyTask` 反馈复位失败或拒绝的内部消息。界面通常不需要发送该 TLV，也不应把它作为 SOC/HMI 侧复位命令。

| 项目 | 值 |
| ---- | -- |
| 方向 | MCU 内部：owner task -> `AlarmSafetyTask` |
| Cmd | `CMD_ALARM_EVT_RESPONSE` (`0x82`) |
| Tlv-Type | `TLV_ALARM_EVT_RESET_RESULT` (`0x04`) |
| Tlv-Len | `3` |

payload:

| Value 字节 | 字段 | 类型 | 说明 |
| ---------- | ---- | ---- | ---- |
| `value[0..1]` | `alarm_code` | `uint16_t LE` | 激光器报警时为 `1301` |
| `value[2]` | `result` | `uint8_t` | `1`: failed；`2`: denied |

当前结果值：

| 值 | 宏 | 含义 |
| -- | -- | ---- |
| `0x01` | `ALARM_RESET_RESULT_FAILED` | 业务任务尝试复位但执行失败 |
| `0x02` | `ALARM_RESET_RESULT_DENIED` | 业务任务当前状态拒绝复位 |

## 4. 激光器手动功率设置

`TLV_LASER_POWER_SET` 用于界面临时设置激光器功率百分比。

| 项目 | 值 |
| ---- | -- |
| 方向 | SOC/HMI -> MCU |
| Port | `PORT_LASER_TASK` (`0xAA`) |
| Cmd | `CMD_LASER_MANUAL_CONTROL` (`0x87`) |
| Tlv-Type | `TLV_LASER_POWER_SET` (`0x01`) |
| Tlv-Len | `1` |

payload:

| Value 字节 | 字段 | 类型 | 说明 |
| ---------- | ---- | ---- | ---- |
| `value[0]` | `laser_power_percent` | `uint8_t` | 功率百分比，范围 `0..100` |

固件收到后会记录待执行功率设置，由 `LaserTask` 在任务循环中执行实际激光器写寄存器流程。

## 5. 激光器功率恢复外控

`TLV_LASER_POWER_RESET` 用于取消界面手动功率控制，恢复外部模拟量控制。

| 项目 | 值 |
| ---- | -- |
| 方向 | SOC/HMI -> MCU |
| Port | `PORT_LASER_TASK` (`0xAA`) |
| Cmd | `CMD_LASER_MANUAL_CONTROL` (`0x87`) |
| Tlv-Type | `TLV_LASER_POWER_RESET` (`0x02`) |
| Tlv-Len | `0` |

payload: 无。
