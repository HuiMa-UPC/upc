# 视觉协作：基板测高与高度校准

振镜点位、Z 轴、LUT 都在 Glavo。Visual 只对最新帧给出红光斑质心，不查 LUT、不算高度。

| 角色 | 路径 |
|------|------|
| 光斑分割 | `app/visual/lib/plate_height_pipeline.*` |
| 配置 | `/userdata/visual/plate_height_config.json` |
| 单帧质心 | `app/visual/lib/visual_service.cpp` → `detect_laser_spot` |
| 点表 / 门限 / 回零常量 | `app/glavo/lib/height_points.hpp` |
| 调试页校准 | `app/glavo/lib/height_calibration.*` |
| 打印前测高 | `app/glavo/lib/plate_height_measure.*` |
| 二维 LUT | `app/glavo/lib/height_lut_2d.*` |
| 起印 gate / 照明 / 回零 | `app/glavo/lib/glavo_service.cpp` |

测高 8 点与光路检测的中心+四角不是同一张表。改点表必须重新校准。

板端文件一律在 **`/userdata/visual/`**（不再用 `/etc/visual/`）。若 UI 仍带旧路径 `/etc/visual/height_lut.txt`，Glavo 会改写到新路径。

---

## 两条流程

| | 高度校准 | 打印前测高 |
|--|----------|------------|
| 入口 | Laser 页 `Height Calibration` → Start | Other 页 `Plate Height Adj` **开** + Confirm Print |
| 默认 | 手动触发 | 开关默认关，且**只活在本次 Glavo 进程**；重启后回到 Off |
| 作用 | 扫 Z 网格，原子写 `/userdata/visual/height_lut.txt` | 用已有 LUT 测 8 点，AXIS_INC 把基板调到工作面 |
| 失败 | UI 显示 Failed，不覆盖成功表 | **不阻断打印**，最多挂平整度告警 |

没有有效 LUT 时，即使开关打开也跳过测高。

打印预检顺序（Confirm Print 之后、出光之前）：

```text
关舱灯 + Red_On
  → 光路检测（若开；失败阻断打印）
  → 再发关灯
  → 基板测高（若 Adj 开且 LUT 有效；失败不阻断）
  → open/parse / 首层参考图 / begin_sending
```

这段预检**只发关灯 `0x07`，不发开灯 `0x06`**。调试页单独校准结束仍开舱灯。

## 照明

| 时机 | 舱灯 | 瞄准红光 |
|------|------|----------|
| Confirm Print / 光路开始 / 测高开始 / 校准开始 | TLV `0x07` 关 | 先串口 `0x12` 关激光使能，出队后再 TCP `CMD=0x0A` `Red=3`（调试页 **Red_On**） |
| 校准结束 | TLV `0x06` 开 | **不关** |
| 测高结束 / 光路结束 | 保持关 | **不关** |

振镜绝对移动 LD=`01 00`，途中红光保持。打印跳转 LD=`00 00`。

舱灯与调试页 Light 同一串口包，MCU 只有一路，不能左右独立。

## Z 零点（无绝对编码器）

MCU Z Home 停在 **1.00 mm**，软件把它当作逻辑 0。`wait_z` 用 MCU 上报值，逻辑高度要 **+1 mm**。AXIS_INC 仍按逻辑高度差下发（下降为负，单位 μm）。

校准和打印前测高**每次回零**：

1. `AXIS_INC -20 mm`（先拉开，避免 Home 方向错）
2. 最多等 **8 s**（编码器若在动则提前结束；报 0 不空等 30 s）
3. 再发 Z Home，等 MCU Z=**1.00**（超时 30 s）

回零前调试页电机须已使能，否则 MCU 一直报 `Z=0`，Home 会失败。

## 8 个振镜点（mm）

扫描顺序。全部 `y ≥ 0`，避开 `y < 0` 强反光。每点 settle **300 ms** 再要质心。

| i | X | Y |
|---|---|---|
| 0 | +20 | 0 |
| 1 | +30 | 0 |
| 2 | +30 | +30 |
| 3 | +20 | +20 |
| 4 | -20 | 0 |
| 5 | -30 | 0 |
| 6 | -30 | +30 |
| 7 | -20 | +20 |

## Visual

1. `GLAVO_Visual_PlateHeight_Session_Start_Ntf`：起流预热（可与光路/首层共用 Camera）。
2. `GLAVO_Visual_Laser_Spot_Measure_Req`：取**最新**紧凑 NV12 的 **Y 平面**，跑 `detect_laser_spot()`。
3. `APP_Visual_Laser_Spot_Measure_Rsp`：`ok + laser_x/y`。`ok=0` 时 Glavo 跳过该点。
4. `GLAVO_Visual_PlateHeight_Session_Stop_Ntf`：会话结束。

配置 `/userdata/visual/plate_height_config.json`（缺文件用头文件默认值，Visual 不崩）：

| 字段 | 当前值 | 含义 |
|------|--------|------|
| `roi_quad` | 四边形像素 | 搜索区；空则整图 |
| `fixed_thresh` | 250 | 二值化阈值 |
| `min_area` | 2 | 连通域面积下限 |
| `max_area` | 200 | 面积上限 |

json 里的 `lut_path` **生产路径不用**（`detect_laser_spot` 不算高度）。删掉不影响校准/测高。

## LUT

`/userdata/visual/height_lut.txt`，Tab 分隔 5 列：

```text
# 8-point galvo calibration: height galvo_x galvo_y img_x img_y
height  galvo_x  galvo_y  img_x  img_y
```

Glavo 按 `(galvo_x, galvo_y)` 分组线性回归 `img = a0 + a1·h`，反查：

```text
h = (a1·(img_x-a0) + b1·(img_y-b0)) / (a1² + b1²)
```

校准网格：逻辑 **-5…12 mm**、步长 1 mm，±1 mm 内补 0.25 mm。24 层 × 8 点 = **192** 行。采完后 `tmp`+`rename` 一次写入，再按上面的回零流程收尾。

## 打印前测高（Adj 开且 LUT 有效）

在光路检测之后：

1. `AXIS_INC -20` → 短等 → Z Home → 等 MCU Z=1.00。
2. 粗 LUT 扫 8 点，中位数 `h_med`，AXIS_INC `-h_med`。
3. 精 LUT（只用 ±1 mm 样本）最多 5 轮：
   - `|h_med| ≥ 30 μm`：再调一次 Z。
   - `|h_med| < 30 μm` 且 8 点齐全、相对中位数最大偏差 ≤ 200 μm：再微调一次，通过。
   - 五轮仍不过：挂 `PlateHeightFlatnessWarn`，不阻断打印。

| 消息 | 方向 | 作用 |
|------|------|------|
| `UI_Debug_PlateHeight_Adj_{Set,Get}_Ntf` | UI↔Glavo | 开关，仅本次运行，默认关 |
| `GLAVO_Debug_PlateHeight_Adj_Ntf` | Glavo→UI | 回读 |
| `UI_Glavo_Height_Calib_Start_Req` | UI→Glavo | 启动校准 |
| `GLAVO_UI_Height_Calib_Progress_Ntf` | Glavo→UI | stage 0 开始 / 1 采集 / 2 完成 / 3 失败 |
| `GLAVO_Visual_PlateHeight_Session_{Start,Stop}_Ntf` | Glavo→Visual | 起流 / 停流 |
| `GLAVO_Visual_Laser_Spot_Measure_Req` | Glavo→Visual | 要质心 |
| `APP_Visual_Laser_Spot_Measure_Rsp` | Visual→Glavo | `ok + x/y` |
