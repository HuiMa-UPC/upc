# 视觉协作：基板测高与高度校准

本文面向视觉算法同学。振镜点位、Z 轴 AXIS_INC、LUT 拟合都在 Glavo；你们只需要在最新帧上给出红光斑质心。

配套代码：

| 角色 | 路径 |
|------|------|
| 光斑分割 | `app/visual/lib/plate_height_pipeline.*` |
| 配置 | `/etc/visual/plate_height_config.json`（`fixed_thresh=250`） |
| 取流 / 单帧质心 | `app/visual/lib/visual_service.cpp` |
| 校准 / 打印前测高 | `app/glavo/lib/height_calibration.*`、`plate_height_measure.*` |
| 二维 LUT | `app/glavo/lib/height_lut_2d.*` |

## 流程

1. Glavo 关舱灯、开红光，起 `PlateHeight` 视觉会话。
2. 振镜走到 8 个 y≥0 点，settle 300 ms。
3. 发 `GLAVO_Visual_Laser_Spot_Measure_Req`（空 payload）。
4. Visual 取最新紧凑 NV12 的 Y 平面，跑 `detect_laser_spot()`，回 `ok + laser_x/y`。
5. Glavo 用 5 列 LUT 反求高度。Visual **不要**查 LUT。

8 点（mm）：`(±30,0) (±35,0) (±30,10) (±30,20)`。改点表必须重新校准。

## 配置

部署 `plate_height_config.json` 到 `/etc/visual/`。缺文件时分割用头文件默认阈值。
