# 视觉协作：基板测高与高度校准

本文面向视觉算法同学。振镜点位、Z 轴、LUT 拟合都在 Glavo；Visual 只在最新帧上给出红光斑质心。

配套代码：

| 角色 | 路径 |
|------|------|
| 光斑分割 | `app/visual/lib/plate_height_pipeline.*` |
| 配置 | `/etc/visual/plate_height_config.json` |
| 取流 / 单帧质心 | `app/visual/lib/visual_service.cpp` |
| 点表 / 门限 | `app/glavo/lib/height_points.hpp` |
| 调试页校准 | `app/glavo/lib/height_calibration.*` |
| 打印前测高 | `app/glavo/lib/plate_height_measure.*` |
| 二维 LUT | `app/glavo/lib/height_lut_2d.*` |
| 开关 / 起印 gate | `app/glavo/lib/glavo_service.cpp` |

测高 8 点与光路检测的中心+四角不是同一张表。改点表必须重新校准，旧 LUT 不能混用。

---

## 两条流程

| | 高度校准 | 打印前测高 |
|--|----------|------------|
| 入口 | Laser 页 `Height Calibration` → Start | Other 页 `Plate Height Adj` **开** + Confirm Print |
| 默认 | 手动触发 | 开关默认关，关着不测、不调 Z |
| 作用 | 扫 Z 网格，写 `/etc/visual/height_lut.txt` | 用已有 LUT 测 8 点，AXIS_INC 把基板调到工作面 |
| 失败 | UI 显示 Failed，不写/不覆盖成功表 | **不阻断打印**，最多挂平整度告警 |

校准跑完才有 LUT。没有有效 LUT 时，即使开关打开也会跳过测高。

---

## 照明与 Z 零点

开始（校准 / 测高，以及 Confirm Print 本身）：

- 关舱灯：串口 TLV `0x07`（与调试页 Light Off 同一包）
- 开瞄准红光：TCP `CMD=0x0A` `Stop=0 Pause=0 Red=3`（调试页 **Red_On**，不发串口 `0x12`）
- 振镜绝对移动 LD=`01 00`，途中红光保持

结束（校准结束 / 测高结束）：

- 只开舱灯（TLV `0x06`）
- **红光不关**

MCU Z Home 停在 **1.00 mm**。软件把这个平面当作逻辑 0；`wait_z` 用 MCU 上报值，须加 1 mm。AXIS_INC 仍按逻辑高度差下发。

---

## 8 个振镜点（mm）

顺序即扫描顺序。全部 `y ≥ 0`，避开 `y < 0` 强反光。

| i | X | Y |
|---|---|---|
| 0 | +20 | 0 |
| 1 | +30 | 0 |
| 2 | +30 | +30 |
| 3 | +20 | +20 |
| 4 | -20 | 0 |
| 5 | -30 | 0 |
| 6 | -30 | +30 |
| 7 | -20 | +20 |

每点 settle **300 ms** 再要质心。

## Visual 要做什么

1. `GLAVO_Visual_PlateHeight_Session_Start_Ntf`：起流预热（可与光路/首层共用 Camera 流）。
2. `GLAVO_Visual_Laser_Spot_Measure_Req`（空 payload）：取**最新**紧凑 NV12 的 **Y 平面**，跑 `detect_laser_spot()`。
3. 回 `APP_Visual_Laser_Spot_Measure_Rsp`：`ok + laser_x/y`（像素质心）。`ok=0` 时 Glavo 跳过该点。
4. `GLAVO_Visual_PlateHeight_Session_Stop_Ntf`：会话结束。

Visual **不要**查 LUT、不要算高度。分割失败只回 `ok=0`。

配置 `/etc/visual/plate_height_config.json`（缺文件用头文件默认值）：

| 字段 | 当前值 | 含义 |
|------|--------|------|
| `roi_quad` | 四边形像素 | 搜索区；空则整图 |
| `fixed_thresh` | 250 | 二值化阈值 |
| `min_area` | 2 | 连通域面积下限（像素） |
| `max_area` | 200 | 面积上限 |

## LUT

文本 5 列，Tab 分隔：

```text
# 8-point galvo calibration: height galvo_x galvo_y img_x img_y
height  galvo_x  galvo_y  img_x  img_y
```

Glavo 按 `(galvo_x, galvo_y)` 分组做线性回归 `img = a0 + a1·h`，反查：

```text
h = (a1·(img_x-a0) + b1·(img_y-b0)) / (a1² + b1²)
```

校准默认网格：逻辑高度 **-5…12 mm**、步长 1 mm，并在 ±1 mm 内补 0.25 mm 细点。全部采完后**一次性原子写盘**，再回 Home。

---

## 打印前测高（开关打开且 LUT 有效）

在光路检测之前：

1. Z Home → 等 MCU Z=1.00。
2. 粗 LUT 扫 8 点，中位数 `h_med`，AXIS_INC `-h_med`。
3. 精 LUT（只用 ±1 mm 样本）最多 5 轮：
   - `|h_med| ≥ 30 μm`：再调一次 Z。
   - `|h_med| < 30 μm` 且 8 点齐全、相对中位数最大偏差 ≤ 200 μm：再微调一次，通过。
   - 五轮仍不过：挂 `PlateHeightFlatnessWarn`，不阻断打印。

IPC：

| 消息 | 方向 | 作用 |
|------|------|------|
| `UI_Debug_PlateHeight_Adj_{Set,Get}_Ntf` | UI↔Glavo | 开关，仅本次运行，默认关 |
| `GLAVO_Debug_PlateHeight_Adj_Ntf` | Glavo→UI | 回读 |
| `UI_Glavo_Height_Calib_Start_Req` | UI→Glavo | 启动校准 |
| `GLAVO_UI_Height_Calib_Progress_Ntf` | Glavo→UI | stage 0 开始 / 1 采集 / 2 完成 / 3 失败 |
| `GLAVO_Visual_PlateHeight_Session_{Start,Stop}_Ntf` | Glavo→Visual | 起流 / 停流 |
| `GLAVO_Visual_Laser_Spot_Measure_Req` | Glavo→Visual | 要质心 |
| `APP_Visual_Laser_Spot_Measure_Rsp` | Visual→Glavo | `ok + x/y` |
