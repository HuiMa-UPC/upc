# Snowpod 软件功能黑盒 QA 测试用例

> 文档版本：v1.0  
> 更新日期：2026-10-09  
> 适用软件：设备端 `rongsu_ui`、`rongsu_glavo`、`rongsu_camera`、`rongsu_media`、`rongsu_xfr`、`rongsu_visual`、`rongsu_mqtt`  
> 测试类型：黑盒功能测试（屏幕、实物动作、配套切片软件、云端控制台可观察结果）

本文件按当前代码的对外行为编写。通过条件只看操作者能直接确认的结果：界面文案与状态、门/轴/灯/风扇等实物动作、本机文件列表与历史记录、切片软件或云端控制台的返回。不把进程日志、内部消息名、耗时统计当作通过条件。

更早的 [`软件功能QA测试文档.md`](软件功能QA测试文档.md) 含日志级回归，其中若干界面描述已与现版不符。功能验收以本文件为准。

## 1. 判定口径

1. 危险动作（开门、运动、激光、风机、升级）只在安全工装和授权环境下执行。
2. 同一条用例里，界面提示与实物结果必须一致。按钮有反馈但设备没动，判失败。
3. 文案以屏幕英文为准。大小写、换行不影响通过；意思相反或关键状态缺失判失败。
4. 第 3 节列出的能力是占位或已知缺口，不按已交付功能判失败。测到时记为「与已知行为一致」即可。

## 2. 环境与测试数据

| 项目 | 要求 |
| --- | --- |
| 设备 | 显示屏、MCU、相机、外门/内门、Z/S/D 轴可用；激光与运动用例必须上安全工装 |
| 启动 | `scripts/rongsu.sh start`。正常上电后应直接进入首页，无需手点进程 |
| 网络 | 一个密码正确的 Wi-Fi、一个密码错误的 Wi-Fi；切片软件与设备在同一局域网 |
| 云端 | 可激活的测试账号、可订阅遥测与命令回执的测试控制台、可收 RTSP 的播放端 |
| 存储 | `/userdata` 可写；容量用例需能把内部存储推到 90% 以上（若存储页能读到用量） |

| 编号 | 数据 | 用途 |
| --- | --- | --- |
| D01 | 可完整打完的本地 G-code（层数少、耗时短） | 打印主流程 |
| D02 | 可导入的 `.3mf`（包内仅一份 G-code，带层数与预估时长） | Wi-Fi 传输 |
| D03 | 可导入的 `.ovf` | Wi-Fi 传输（OVF 切片） |
| D04 | 损坏或截断的 G-code / 3MF / OVF | 失败提示 |
| D05 | 扩展名不是 `.3mf` / `.ovf` 的文件 | 格式拒绝 |
| D06 | 含多层、能产生延时帧的短作业 | 历史与延时播放 |
| D07 | 至少一张由本机拍下的照片 | 相册 |

## 3. 不按已交付功能验收

下列行为与当前实现一致。单独出现时不要记缺陷；若产品已宣布交付，再单独立项。

| 项 | 当前可见行为 |
| --- | --- |
| 设置 → Account、Privacy & Security | 占位页，没有账号或隐私设置可改 |
| 设置 → Display & Brightness 的熄屏时长 | 只能选中打勾，不熄屏、不记住，重启恢复默认 |
| 设置 → Storage 的格式化、U 盘容量、文件管理行 | 界面可点或置灰，不作为真实格式化/文件管理验收 |
| 回粉盒满、废粉盒满弹窗 | 没有传感器自动弹出，只能在调试页注入 |
| Wi-Fi 传输 PIN 弹窗的取消 | 只关掉屏幕上的窗，配对会话仍有效，手机仍可能配对成功 |
| PIN 过期 | 弹窗不会自己消失，需手动关 |
| 接收进度窗的 Cancel Transfer | 关掉后，传输还在进行时窗口会再次出现 |
| 转运盒「装盒到位」 | 按钮由灰变可点靠定时，不检测盒子是否真的装好 |
| 转运失败或中止 | 停在转圈页，没有自动超时、重试或关闭 |
| 首页第二颗料桶余量 | 显示的不是独立的 2 号桶余量 |
| 结果页吹粉未完成时的 RETRIEVE | 按钮保持可点；吹粉进行中点它会被拦住并提示，而不是事先变灰 |
| 舱外 PM2.5 | 首页「Home PM2.5」与机身小屏是同一显示值；调试页顶栏才是舱外实测 |

## 4. 用例

优先级：P0 每次发版必测，P1 改到对应模块时必测，P2 抽测或专项。

### 4.1 开机、导航与首页

| ID | 级 | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- | --- |
| BB-BOOT-01 | P0 | 设备断电 | 上电，等待首页出现 | 进入首页。问候语随当前时段为 Good morning / Good afternoon / Good evening，副标题为 Ready for your next print?。左下有 PRINT，右下有 SLIDE TO UNLOCK。侧栏五项可点：首页、监控、历史、设置、消息。进程不反复重启，屏幕不花、不黑死 |
| BB-BOOT-02 | P0 | 相机或主控链路异常（可拔相机或停掉对应服务后再启界面） | 打开首页，再进监控页 | 界面不崩溃。预览无画面或保持等待，不得假装已在打印。PRINT 在无法准备文件时不得进入「正在打印」 |
| BB-NAV-01 | P0 | 已在首页 | 依次点侧栏五项，再回到首页 | 每页都能打开、再返回。首页、监控为浅色工作区。监控、历史、设置、消息页没有顶部「Wi-Fi + 设备名 + 状态」条，右上角也没有铃铛。铃铛只在首页 |
| BB-NAV-02 | P1 | 空闲 | 从首页 PRINT 进入选文件，不选文件，点侧栏回首页；再从监控页 PRINT 进入选文件，点侧栏回监控 | 从哪一页进去，侧栏高亮停在那一页；返回也回到那一页，而不是总回首页 |
| BB-HOME-01 | P0 | 环境传感器有读数 | 看首页四宫格：温度、氧浓度、湿度、气压 | 四项为实时数字加单位。传感器无效时对应项为 `--`，不出现负数或乱码。读数会随环境变化更新 |
| BB-HOME-02 | P0 | 首页与监控 Status 都能看到空气质量卡 | 开机看两张卡标题；在任一张卡上切换；切到另一页；重启后再看 | 开机两张都是 Cabin PM2.5。切一张，另一张下次显示时同为 Home PM2.5。重启回到 Cabin。无数据时分级为 `--`、读数空白、色条上没有游标。有数据时为一位小数，单位 ug/m3。Home 档读数与机身小屏逐位一致 |
| BB-HOME-03 | P1 | 两颗料桶胶囊可见 | 改变粉量或滤芯相关上报，观察胶囊数字 | 数字在 0–100 范围内更新，不出现崩溃。2 号胶囊允许与滤芯余量相同（见第 3 节） |
| BB-HOME-04 | P0 | 外门关闭，空闲 | 把首页滑块拖过一半后松手；再滑到底松手 | 未滑到底会弹回，门不开。滑到底出现 RELEASE TO OPEN，松手后进入开门流程（见 BB-DOOR-01） |

### 4.2 开门

三个入口：首页滑块、监控页 Manual 底部 OPEN、打印结束后 RETRIEVE。空闲开门成功后直接回到原页面，不再要求确认「门已关上」。

| ID | 级 | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- | --- |
| BB-DOOR-01 | P0 | 外门关，舱内粉尘未超标，PM2.5 Check 为开 | 首页滑到底松手 | 出现 Checking PM2.5... 与转圈。检测通过后门打开。成功后弹窗消失，回到空闲。取消在门开之前有效，取消后门保持关闭 |
| BB-DOOR-02 | P0 | 人为使开门前粉尘超标（或调低阈值），PM2.5 Check 为开 | 再次从首页开门 | 标题变为 Cleaning powder...，风机运转。净化结束后才开门。净化过程中点 Cancel，先显示 Stopping fan...，风机停，门不开 |
| BB-DOOR-03 | P1 | PM2.5 Check 关掉 | 粉尘超标时从首页开门 | 不再先吹风净化，按其余门控直接尝试开门 |
| BB-DOOR-04 | P0 | 外门机构被挡住，连续开不了 | 滑到底并等待 | 最多尝试约 3 次。仍失败则提示 Door did not open，回到进入前的页面，不再无限转圈 |
| BB-DOOR-05 | P1 | 空闲，停在监控 Manual，外门已开 | 看底部 OPEN | OPEN 为灰，点了没反应。门关上后恢复可点 |
| BB-DOOR-06 | P1 | 空闲，外门关，停在 Manual | 点 Inner Door | 弹出 Open the outer door first，滑条为 SLIDE TO UNLOCK。滑到底后转圈标题为 Opening the door...（不是 Checking PM2.5...）。外门打开后按刚才的意图开或关内门。Cancel 后，之后自己开外门时内门不得自己动 |

### 4.3 选文件与开始打印

默认情况下，点 PRINT 不先问「是否已放入打印版」（调试页 Skip Plate Prompt 默认跳过这张窗）。关掉该跳过后，应先出现放版确认，选已放入才进文件列表。

| ID | 级 | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- | --- |
| BB-FILE-01 | P0 | 本机已有 D01，且出现在 Local 列表 | 首页点 PRINT，打开 Local | 只列出已导入的任务：文件名、时长、耗材、大小与清单一致。目录里多放一个未导入文件，刷新后仍不出现。列表为空时不崩溃 |
| BB-FILE-02 | P0 | U 盘内有当前版本能打印的文件 | 切到 USB，刷新；拔出 U 盘再刷新 | 插入时能看到文件。拔出或空盘后列表清空或给出空提示，不崩溃 |
| BB-FILE-03 | P0 | 已选中 Local 的 D01 | 点删除，先取消，再确认 | 取消后文件还在。确认后该文件从列表消失，再次进入仍然没有 |
| BB-FILE-04 | P0 | 未选文件；再选中 D01；再切 Tab；再取消选中 | 每次看 Confirm Print | 未选中时不可开始。选中后可点，点后进入二次确认。换文件、换 Tab、取消选中后，不能拿上一个文件直接开打 |
| BB-FILE-05 | P0 | D01 在 Local；另备 U 盘上的可打印文件 | 分别二次确认开始 | 出现 Preparing Print File。成功后弹窗关闭，自动进入监控页打印态，任务名与所选文件一致。U 盘文件会被复制到本机，之后 Local 能看到 |
| BB-FILE-06 | P0 | D04 或清单有记录但文件已丢 | 二次确认 | 准备失败有明确失败提示，回到空闲。不进入 Printing，激光与扫描轴不启动 |
| BB-FILE-07 | P0 | 一单已结束但还在结果页，尚未取件 | 从侧栏或 PRINT 尝试再选文件开打 | 不能进入选文件，也不能启动第二单 |

### 4.4 打印过程（监控页 Job）

选文件确认后落在监控页，不是首页。摄像头在进入监控页后应一直有画面（全屏切换时画面不跳变、不黑一下）。

| ID | 级 | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- | --- |
| BB-PRINT-01 | P0 | 门控按第 4.5 节默认值，基板与门状态满足开打 | 用 D01 开始 | 右栏在 Job。自检阶段标题依次出现实际会做的检查（外门、关内门、光路、测高、氧浓度等），被关掉的检查不出现。准备进度走完后标题回到 Printing，进度从 0% 重新走打印进度。底部为暂停与终止 |
| BB-PRINT-02 | P0 | 打印中 | 看进度、Time left、Total Cons. | 百分比与进度条只增不减（暂停除外）。有预估时长时 Time left 随进度减少；没有预估时为 `--`。打印过程中耗材为 `--` |
| BB-PRINT-03 | P0 | 打印中 | 点暂停，再点恢复；快速连点暂停 | 暂停后状态为 Paused，扫描停止。恢复后回到 Printing 并继续往后打，不从头开始。连点不会卡在相反状态 |
| BB-PRINT-04 | P0 | 打印中 | 点终止后在确认框取消；再点终止并确认 | 取消后作业继续。确认后进入结果态，文案为 Print Terminated，不显示 100% 进度蒙版。扫描停止 |
| BB-PRINT-05 | P0 | D01 能自然打完 | 等待结束 | 进度到 100% 后进入结果态，文案为 Print Complete。Time left 改为 Time used，显示实际耗时。有耗材数据时 Total Cons. 为克数，没有则为 `--` |
| BB-PRINT-06 | P0 | 打印中切到设置再回监控 | 观察 Job 卡 | 进度、暂停/终止、预览都还在，不回到空闲空卡片 |
| BB-PRINT-07 | P1 | 打印中 | 点全屏，再点回非全屏；同时看预览 | 全屏只是横向多露出一截，画面比例不跳。来回切换不黑屏、不花屏 |
| BB-PRINT-08 | P1 | 外门在开打前未关，Outer Door Check 为开 | 开始打印 | 弹出外门确认。Confirm 后若门仍开，会再次询问。Cancel 后不再卡在这一步，继续后续内门等流程（与「完全跳过外门和内门」不是同一开关） |
| BB-PRINT-09 | P0 | 正式扫描已经开始后把粉打空（两路粉位都空），Powder Low Check 为开 | 观察 | 作业变为暂停，弹出粉舱已空。未补粉时主按钮不可点。补粉后主按钮可点，继续后能接着打。取消是「本次忽略后续缺粉」，窗口关闭并保持暂停，之后再缺粉不再弹 |
| BB-PRINT-10 | P1 | Powder Low Check 为关 | 同样把粉打空 | 不因缺粉自动暂停，也不弹粉舱已空 |

### 4.5 打印前检查（设置 → Advanced Print）

进入该页后开关会与设备当前值对齐。下表是冷启动后的产品初值。只在本次运行有效的项，重启应回到初值。

| 开关 | 冷启动初值 | 关掉后，操作者应看到 |
| --- | --- | --- |
| Outer Door Check | 开 | 起印不再因外门打开而停下来询问 |
| PM2.5 Check | 开 | 开门不再先做粉尘检测和吹风 |
| Inner Door Vision | 关 | 不因内门视觉挡板拦截 |
| Plate by Pattern | 开 | 起印不做基板图案在位确认 |
| Plate by Height | 关 | 不因高度判基板在位 |
| Optical Path Check | 开 | Job 卡不出现 Optical path check，也不做五点红光 |
| Plate Height Adj | 开 | 不做打印前测高；无校准表时也不因此拒绝开打 |
| Oxygen Check | 开 | 不出现 Checking oxygen，氧浓度不达标也能往下走 |
| Powder Low Check | 关 | 打印中缺粉不暂停、不弹窗 |
| Keep Z Position | 关 | 打开后整单打印不动 Z（不起印下移、不测高抬升、开关内门前不降 Z）。Manual 与调试页的 Z 点动、回零也不执行 |
| Transfer Box | 开 | 关掉后，取件开门成功即回空闲，不出现装盒三步。不记到磁盘，重启回到开 |
| Auto Print After Transfer | 关 | 见 BB-XFR-06。打开时提示 Slicer will auto-start print；关掉时提示 Transfer only, no auto-start。记在本机，重启后保持上次选择 |

| ID | 级 | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- | --- |
| BB-GATE-01 | P0 | 刚重启 | 打开 Advanced Print，核对上表 | 初值与表一致。拨动任一开关后离开再进入，本次运行内保持。整套进程重启后，除 Auto Print After Transfer 外都回到上表初值。Auto Print 保持上次选择 |
| BB-GATE-02 | P0 | Optical Path Check 开，光路正常 | 用 D01 起印，看 Job 标题 | 出现 Optical path check，并带当前点序号（n/5）。五点完成后进入下一步。人为遮挡红点使其失败时，作业终止，不开始出光扫描 |
| BB-GATE-03 | P0 | Plate Height Adj 开，且已有高度校准 | 起印 | 出现 Plate leveling。测高失败或没有校准表时拒绝开打，有失败提示，不进入扫描 |
| BB-GATE-04 | P1 | Keep Z Position 打开 | 起印，同时在 Manual 点 Z 的 Top / 上下 / 复位 | 平台高度在整单准备和打印中保持不动。Manual 的 Z 操作没有位移 |
| BB-GATE-05 | P1 | 在 Calibration 把 Work Height 改成合法毫米值（默认 1）后开始一次测高开打 | 观察平台最终工作高度 | 数值被接受。非法字符无法输入。高度校准 Start 后状态从 Idle 变为进行中，并有 Height calibration started 提示。校准进行中重复点 Start 不得叠出两次运动 |
| BB-GATE-06 | P2 | 调试页 Skip Plate Prompt 关掉（默认是跳过） | 点 PRINT | 先出现是否已放入打印版。未放入不能进文件列表。已放入后进入选文件。该开关重启后恢复为跳过 |

### 4.6 结果、吹粉、取件与转运盒

| ID | 级 | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- | --- |
| BB-END-01 | P0 | Transfer Box 为开。D01 自然完成 | 进入结果页后先不要点 RETRIEVE | 自动开始吹粉，状态为净化中，风机动作与按钮动画一致。再点吹粉可停，再点可再开。吹粉进行中点 RETRIEVE 被拒绝并有提示，作业仍停在结果页 |
| BB-END-02 | P0 | 吹粉已停或已完成，Transfer Box 为开 | 点 RETRIEVE，滑条滑到底 | 弹窗标题与结束态一致（完成 / 终止）。滑条字为 SLIDE TO RETRIEVE。未滑到底松手会回弹，门不开。滑到底后走粉尘检查（若开启）并开门。开门成功后依次为：装盒（Install the box and pull out the divider，按钮先灰后可点 Done）、转运（只有转圈，不能关）、抽盒（Unlock and Remove the Box 可点）。点完成后提示 Transfer complete，回到空闲 |
| BB-END-03 | P0 | 同一次运行内把 Transfer Box 关掉（不要重启） | 完成一单后取件并滑到底 | 开门成功后直接回空闲，不出现装盒、转运、抽盒。重启后该开关回到开，取件重新走三步 |
| BB-END-04 | P0 | Transfer Box 为开 | 在自检阶段（还在 Checking outer door / Optical path check 等，进度尚未回到 Printing 0%）终止；另做一单在 Printing 之后终止 | 自检阶段终止：不自动吹粉，消息里不出现取件前请先净化。取件弹窗说明为 No part printed. Slide to open the door.，滑条为 SLIDE TO UNLOCK。开门后直接回空闲，不走转运盒。打印中终止：仍自动吹粉，取件仍走转运盒三步 |
